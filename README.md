# Higher Primary School Jagalbet

React website for Higher Primary School Jagalbet with sections for faculty,
events, gallery, about us, contact information, and a simple admin upload page.

## Admin Login

Open `/admin` and use:

```text
Username: admin
Password: school123
```

Admin uploads are stored in the browser on the same computer using localStorage.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
